# Horizon Background Sources

24 square PNG source backgrounds, generated individually using built-in image_gen.
Not converted or registered in the app yet. Exact prompts and status are in
[generation.json](generation.json); the review gallery is [index.html](index.html).

## Placement intent

- Suggested converted logical size: 1200 x 1200, providing 20% overscan beyond
  the longest standard page dimension (1000 logical units).
- High base horizon around 38% down from the source, with open lower foreground.
  This is a prompt target; inspect actual line placement before conversion.
- Preserve the full square canvas/viewBox, including blank foreground and sky.
  Do not auto-trim these to their ink bounds like isolated stickers.
- Lines deliberately reach the side edges for cropping and horizontal adjustment.
  Extend/close paint regions invisibly to canvas edges during conversion; do not
  add visible rectangle outlines. Review skies, gaps and region ownership then.
- Source pixel size is independent of logical sticker size. We requested about
  1024 x 1024 rather than increasing image resolution for the overscan.
