# Archived icon inspiration

Icon redesign is deferred at the user's request. The app uses its original icons
and button styling. These source assets remain available for future inspiration;
none is imported by the app.

- `paper-charms/`: the smooth gradient-based delete, book plus/check, printer and
  export SVGs from the four-action trial.
- `../printer.svg` and `../saved-*.svg`: the later compact Enchanted Ink-inspired
  hand-redrawn SVGs. The user found these insufficiently faithful to the reference.
- [Concept boards and prompts](../../../../docs/icons/directions/README.md).
- [Actual color-mask/Potrace book proof](../../../../docs/icons/enchanted-ink-trace/index.html).
- [Paper Charms printer study](../../../../docs/icons/paper-charms/printer-study/index.html).

Retain the assets and process notes, but revisit the visual approach before any
future rollout. Large raster originals and draft integration are also preserved
under ignored `work/parked-paper-charms/`; they are not runtime dependencies.
